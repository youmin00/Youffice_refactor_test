개발 목적

1. 개발 배경

대학생이 졸업 작품이나 개인 포트폴리오 프로젝트를 혼자 시작할 때 가장 먼저 만나는 문제는 단순한 기술 부족이 아니다. 아이디어를 요구사항으로 바꾸고, 무엇을 먼저 조사하고 결정해야 하는지 정하며, 여러 선택의 이유와 위험을 기록하는 과정 자체가 어렵다.

GPT나 Gemini 같은 생성형 AI는 코드 작성, 오류 설명, 아이디어 제안처럼 구체적인 질문에 유용한 답을 제공한다. 그러나 답변이 여러 대화에 흩어지기 쉽고, 프로젝트에서 이미 확정한 조건과 아직 모르는 조건, 선택 이유, 실제 시험 결과를 장기간 연결해서 관리하기는 어렵다.

또한 AI가 기획부터 도면, 제작, 시험까지 모두 대신 수행한다고 가정하면 실제 작업과 문서상의 제안이 섞일 수 있다. CAD 도면 작성, 부품 구매, 조립, 코드 실행, 성능·안전 시험은 전문 도구와 실제 환경이 필요한 영역이다. 이를 AI가 완료했다고 표현하면 사용자는 프로젝트의 실제 상태를 잘못 이해할 수 있다.

이러한 문제를 바탕으로 YOUFFICE는 프로젝트를 대신 완성하는 서비스가 아니라, 혼자 프로젝트를 수행하는 학생이 실제 작업을 시작하고 이어갈 수 있도록 준비와 기록을 맡는 AI 프로젝트 오피스로 개발한다.

2. 개발 목적

YOUFFICE의 목적은 사용자의 막연한 아이디어를 다음 행동이 가능한 프로젝트 준비서로 바꾸는 것이다.

사용자가 한 문장 아이디어를 입력하면 유키가 초기 핵심 질문을 최대 3개 안에서 하고 제작 준비 초안을 먼저 보여 준다. 이후 사용자는 결과에 영향을 주는 항목을 횟수 제한 없이 하나씩 선택해 구체화할 수 있다. 사용자가 유키에게 질문·설명·비교를 요청하는 대화는 초기 질문 횟수에 포함하지 않으며, 유키는 그 질문에 먼저 답한다. 사용자가 모르는 항목은 대화를 막지 않고 합리적인 기본 가정 또는 미확인 사항으로 구분한다. 이후 AI 직원들이 요구사항, 선택 기준, 자료와 출처, 기술 준비 조건, 위험 요소, 테스트 계획, 외부 도구에 넘길 일을 역할별로 정리하고 상호 검토한다.

사용자는 이 준비서를 바탕으로 CAD, 개발 환경, 제작 장비 또는 외부 전문가를 이용해 실제 설계·개발·제작·시험을 진행한다. YOUFFICE는 실행 중 발생한 결정, 변경, 오류와 시험 결과를 프로젝트 기록에 연결하고 다음 행동과 보고서로 정리한다.

3. 해결하고자 하는 문제

첫째, 아이디어는 있지만 무엇부터 정해야 할지 몰라 시작하지 못하는 문제를 해결한다.

둘째, AI가 질문을 자동으로 계속 이어가 사용자가 모든 세부사항을 먼저 결정해야 하는 부담을 줄인다. 초기 핵심 질문은 최대 3개로 제한하되, 초안 뒤에는 사용자가 원하는 항목만 횟수 제한 없이 하나씩 구체화하고 비핵심 항목은 기본 가정으로 진행할 수 있게 한다.

셋째, 조사 결과와 일반 AI 답변이 프로젝트의 결정 및 다음 행동과 연결되지 않는 문제를 해결한다.

넷째, 혼자 진행할 때 선택지의 장단점, 위험, 누락을 검토해줄 상대가 부족한 문제를 보완한다.

다섯째, 문서상 제안과 실제 구매·도면·코드·조립·시험 완료 여부가 섞이는 문제를 막는다.

여섯째, 대화, 출처, 요구사항, 결정, 오류, 시험 결과와 보고서가 여러 공간에 흩어지는 문제를 해결한다.

4. 주요 사용자

- 처음으로 졸업 작품이나 규모 있는 개인 프로젝트를 진행하는 대학생
- 아이디어는 있지만 요구사항과 실행 순서를 정하기 어려운 학생
- 함께 검토할 팀원이 부족한 학생
- 자료 조사, 선택 근거, 오류와 시험 기록을 한곳에 관리하고 싶은 학생
- 일반 AI의 답변을 실제 프로젝트의 결정과 다음 행동으로 연결하고 싶은 학생

5. AI 직원별 역할

유키 · 프로젝트 팀장
- 사용자의 목표를 쉬운 말로 정리한다.
- 한 답변에서는 질문을 최대 1개만 하며, 초기 구체화에서는 최대 3개의 핵심 질문 뒤 초안을 먼저 만든다.
- 초안 뒤 사용자가 선택하면 중요한 항목을 횟수 제한 없이 하나씩 더 구체화한다.
- 사용자가 반대로 질문하면 먼저 답하고, 그 답변을 초기 질문 횟수에 포함하지 않는다.
- 확정 정보, 기본 가정과 미확인 사항을 구분한다.
- 제작 준비 계획과 다음 행동을 조율한다.

희정 · 기록 담당
- 요구사항, 결정 사항, 변경 이력과 오류 기록을 관리한다.
- 과거 기록과 현재 요청이 충돌하는지 확인한다.

리오 · 기획 담당
- 목표, 선택 기준, 범위, 예산, 일정과 우선순위를 정리한다.
- 조사 자료가 어떤 결정에 영향을 주는지 연결한다.

미츠리 · 기술 준비 담당
- 기능 구성, 부품·소프트웨어 후보와 호환성 확인 항목을 정리한다.
- CAD·코딩·조립·시험 전에 필요한 요구사항과 외부 도구 전달 체크리스트를 작성한다.

레비 · 검토 담당
- 준비 자료의 오류, 누락, 위험, 근거와 실현 가능성을 검토한다.
- 문서 검토 통과와 실제 장치·코드의 시험 완료를 구분한다.

마코 · 프로젝트 문서 담당
- 직원 결과를 프로젝트 준비서와 진행 기록으로 통합한다.
- 사용자가 직접 할 일, 외부 도구로 넘길 일, 테스트 순서와 미확인 사항을 분명하게 정리한다.

6. 핵심 개발 방향

YOUFFICE가 직접 만드는 핵심 결과물은 완성품이 아니라 프로젝트 준비서이다.

프로젝트 준비서에는 다음 내용이 포함된다.

- 프로젝트 목표와 대상 사용자
- 확정된 요구사항
- 기본 가정과 미확인 사항
- 선택지, 비교 기준과 추천 이유
- 자료 조사 결과와 원문 출처
- 부품·소프트웨어·기술 구성 후보
- 예산과 일정
- 위험 요소와 제작 전 확인사항
- 외부 CAD·개발·제작 도구에 넘길 체크리스트
- 실제 시험 기준과 결과 기록 양식
- 사용자가 지금 수행할 다음 행동

프로젝트가 실제로 시작된 뒤에도 YOUFFICE는 결정 변경, 오류, 시험 결과와 해결 과정을 기록하고 준비서와 보고서를 갱신한다. 다만 실제 구매·도면 작성·코드 실행·조립·성능 시험은 사용자가 전문 도구와 실제 환경에서 수행하고 확인한다.

7. 기존 생성형 AI와의 차별점

기존 생성형 AI가 특정 질문에 대한 좋은 답을 제공한다면, YOUFFICE는 그 답을 프로젝트의 요구사항, 결정, 근거와 다음 행동으로 연결한다.

YOUFFICE의 차별점은 AI 답변 자체의 우월함이 아니라 다음과 같은 프로젝트 운영 구조에 있다.

- 프로젝트별 독립 작업 공간
- 초기 핵심 질문 최대 3개와 사용자 선택형 무제한 구체화
- 확정 정보·기본 가정·미확인 사항의 분리
- 직원별 조사·기획·기술 준비·검토·문서화 역할
- 출처와 선택 이유의 연결
- 사용자 승인 후 준비 자료 작성
- 문서 검토와 실제 실행 완료 상태의 분리
- 결정, 오류, 시험 결과와 보고서의 장기 기록

8. 개발 범위

YOUFFICE가 직접 지원하는 범위
- 아이디어 구체화
- 요구사항과 선택 기준 정리
- 자료 조사와 출처 관리
- 기술 구성 후보와 호환성 확인 항목 정리
- 예산·일정·위험·테스트 계획 작성
- 프로젝트 결정과 오류 기록
- 프로젝트 준비서 및 보고서 작성

외부 도구와 사용자가 수행하는 범위
- 정밀 CAD 도면 작성
- 실제 부품 구매와 재고 확인
- 실물 조립과 가공
- 코드 실행, 배포와 실제 환경 디버깅
- 성능·안전·사용성 시험
- 최종 제작 판단과 책임

YOUFFICE는 외부 실행 결과가 제공되면 이를 분석하고 다음 수정안과 시험 항목을 정리할 수 있지만, 실행 증거 없이 완료됐다고 기록하지 않는다.

9. 기대 효과

사용자는 모든 세부사항을 미리 알지 못해도 프로젝트를 시작할 수 있다. 짧은 대화 뒤 현재 결정, 기본 가정, 남은 확인 사항과 다음 행동을 확인할 수 있으며, 준비서를 교수, 제작자, 개발 도구 또는 다른 AI에게 전달할 수 있다.

프로젝트 도중에는 선택 이유와 문제 해결 과정이 사라지지 않는다. 최종 보고서를 작성할 때도 실제로 수행한 결과와 AI가 제안한 내용을 구분해 사용할 수 있다.

10. 프로젝트 핵심 문장

YOUFFICE는 혼자 프로젝트를 시작하는 학생의 막연한 아이디어를 실제 설계·개발·제작을 시작할 수 있는 준비서로 바꾸고, 진행 중 결정·자료·오류·시험 결과를 끝까지 연결하는 AI 프로젝트 오피스이다.

11. 성공 기준

사용자가 YOUFFICE를 사용한 뒤 다음 질문에 답할 수 있어야 한다.

- 무엇을 만들려는가?
- 무엇이 확정됐고 무엇이 가정인가?
- 어떤 선택지가 있으며 왜 선택하는가?
- 실제 작업 전에 무엇을 확인해야 하는가?
- 외부 도구에서 지금 무엇을 해야 하는가?

이 다섯 가지가 준비되고 사용자가 실제 다음 행동을 시작할 수 있을 때 YOUFFICE의 목적이 달성된 것으로 본다.

YOUFFICE 픽셀 캐릭터·애니메이션 제작 조건문

사용 순서
1. YOUFFICE 애니메이션 실험실에서 현재 직원 기준 이미지를 다운로드한다.
2. 아래 1단계 조건문과 직원 기준 이미지를 외부 이미지 생성 서비스에 함께 입력한다.
3. 완성된 픽셀 캐릭터 PNG를 다시 첨부하고 2단계 조건문으로 행동별 스프라이트 시트를 만든다.
4. 결과 파일을 YOUFFICE 애니메이션 실험실에 올려 프레임 수와 FPS를 시험한다.

======================================================================
1단계: 정지 상태 픽셀 캐릭터 기준 이미지 만들기
======================================================================

아래 조건문에서 [직원 이름]과 [직책]만 바꿔 사용하세요.

[복사 시작]
첨부한 캐릭터 이미지를 [직원 이름], 직책은 [직책]의 공식 외형 기준으로 사용해 주세요.

이 캐릭터를 회사 경영 시뮬레이션 게임에 사용할 수 있는 전신 픽셀 아트 캐릭터로 다시 제작해 주세요.

필수 조건:
- 첨부 이미지의 얼굴 인상, 머리 모양, 머리색, 눈 색, 의상 색, 액세서리와 전체 정체성을 그대로 유지합니다.
- 다른 인물처럼 재해석하거나 의상과 헤어스타일을 임의로 변경하지 않습니다.
- 귀여운 SD 비율의 전신 캐릭터로 제작합니다. 머리는 크고 몸은 작게 표현하되 손과 발이 구분되어야 합니다.
- 정면에서 약간 3/4 방향을 바라보는 자연스러운 기본 대기 자세로 만듭니다.
- 캐릭터 전신과 발끝이 모두 보여야 하며 어느 부분도 잘리면 안 됩니다.
- 한 명의 캐릭터만 출력합니다.
- 실제 픽셀 단위가 분명한 선명한 픽셀 아트로 제작합니다.
- 흐릿한 브러시, 반투명 가장자리, 사진 질감, 3D 렌더링, 부드러운 안티앨리어싱을 사용하지 않습니다.
- 배경, 사무실, 바닥, 그림자, 광원 효과, 글자, 로고, 말풍선, 테두리를 넣지 않습니다.
- 배경은 완전한 투명 배경이어야 합니다.
- 256×256 픽셀 PNG 한 장으로 출력합니다.
- 캐릭터 발바닥 기준선을 이미지 하단에서 12픽셀 위에 맞춥니다.
- 이후 모든 행동 애니메이션의 외형 기준으로 사용할 수 있도록 정돈된 기본 자세로 제작합니다.

출력 전 다음 항목을 반드시 자체 점검해 주세요.
1. 첨부 인물과 동일한 캐릭터인가?
2. 전신이 잘리지 않았는가?
3. 투명 배경인가?
4. 픽셀 아트가 흐리지 않은가?
5. 캐릭터가 정확히 한 명만 있는가?
[복사 끝]

직원별 치환값
- 유키 / 프로젝트 팀장
- 희정 / 비서
- 레오 / 기획팀장
- 마츠리 / 기획 설계 담당
- 레비 / 검수 담당
- 미코 / 보고서 부장

======================================================================
2단계: 행동별 가로 스프라이트 시트 만들기
======================================================================

1단계에서 만든 픽셀 캐릭터 PNG를 첨부한 뒤 사용하세요.
[행동 이름]과 [행동 설명]을 아래 행동표 내용으로 바꿉니다.

[복사 시작]
첨부한 픽셀 캐릭터를 외형과 비율의 절대 기준으로 사용해 주세요.
같은 캐릭터의 [행동 이름] 동작을 보여주는 가로형 픽셀 애니메이션 스프라이트 시트를 제작해 주세요.

행동 설명:
[행동 설명]

필수 조건:
- 첨부 캐릭터의 얼굴, 머리, 눈, 의상, 색상, 액세서리, 신체 비율을 모든 프레임에서 완전히 동일하게 유지합니다.
- 프레임마다 얼굴이나 의상 디자인이 바뀌면 안 됩니다.
- 정확히 8개의 프레임을 왼쪽에서 오른쪽 순서로 한 줄에 배치합니다.
- 각 프레임의 크기는 정확히 256×256 픽셀입니다.
- 전체 이미지 크기는 정확히 2048×256 픽셀입니다.
- 프레임 사이에 여백, 선, 구분선 또는 번호를 넣지 않습니다.
- 모든 프레임에서 캐릭터의 크기와 발바닥 기준선을 동일하게 유지합니다.
- 캐릭터 전신이 모든 프레임에 들어가야 하며 머리카락, 손, 소품, 발끝이 잘리면 안 됩니다.
- 움직이지 않는 신체 부분이 프레임마다 흔들리거나 크기가 달라지지 않도록 합니다.
- 배경, 바닥, 그림자, 광원 효과, 글자, 로고, 프레임 번호, 테두리를 넣지 않습니다.
- 전체 배경은 완전한 투명 배경이어야 합니다.
- 실제 픽셀 아트의 날카로운 가장자리를 유지하고 안티앨리어싱이나 흐림 효과를 사용하지 않습니다.
- 결과는 PNG 스프라이트 시트 한 장으로 출력합니다.

반복 동작이라면 8번째 프레임에서 1번째 프레임으로 자연스럽게 이어져야 합니다.
일회성 동작이라면 마지막 프레임은 다음 정지 화면으로 유지하기 좋은 안정된 자세여야 합니다.

출력 전 다음 항목을 반드시 자체 점검해 주세요.
1. 정확히 8프레임인가?
2. 한 줄로 정렬되어 있는가?
3. 모든 칸이 256×256인가?
4. 발바닥 기준선과 캐릭터 크기가 고정되어 있는가?
5. 모든 프레임에서 같은 캐릭터인가?
6. 투명 배경인가?
[복사 끝]

행동표

1. 대기
행동 설명: 아주 작게 호흡하고 한 번 눈을 깜빡입니다. 몸의 중심과 발 위치는 고정합니다. 8번째 프레임에서 1번째 프레임으로 자연스럽게 이어지는 반복 동작입니다.

2. 생각 중
행동 설명: 한 손을 턱 가까이 가져가고 고개를 아주 조금 기울였다가 기본 자세로 돌아옵니다. 과도하게 좌우로 흔들지 않는 반복 동작입니다.

3. 작업 중
행동 설명: 직원의 직책에 맞는 문서나 태블릿을 확인하고 짧게 입력하거나 표시하는 동작입니다. 손과 시선만 중심적으로 움직이며 발 위치는 고정된 반복 동작입니다.

4. 대화 중
행동 설명: 상대방을 바라보며 한 손으로 작게 설명하고 고개를 한 번 끄덕입니다. 입과 손의 움직임은 작고 자연스러운 반복 동작입니다.

5. 자료 전달
행동 설명: 문서 파일을 몸 앞에서 들어 상대방에게 내미는 동작입니다. 시작은 기본 자세이고 마지막 프레임은 문서를 내민 안정된 자세인 일회성 동작입니다.

6. 업무 완료
행동 설명: 결과 문서를 확인한 뒤 밝게 미소 짓고 한 번 고개를 끄덕이거나 작은 확인 제스처를 합니다. 마지막 프레임은 차분한 완료 자세로 정지하는 일회성 동작입니다. 글자나 체크 아이콘은 넣지 않습니다.

직원별 작업 소품 권장값
- 유키: 프로젝트 계획서 또는 태블릿
- 희정: 메모장 또는 일정 수첩
- 레오: 기획서 또는 클립보드
- 마츠리: 설계 도면 또는 소형 태블릿
- 레비: 검수 체크리스트 또는 돋보기
- 미코: 최종 보고서 또는 문서 파일
